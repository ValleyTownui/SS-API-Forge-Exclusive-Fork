# SS-API-Forge-Exclusive-Fork
SSAPI Forge Fork is a Forge-exclusive fork of SSAPI, designed for improved compatibility and integration with Forge-based Minecraft servers. This version focuses on stable API functionality and seamless support for Forge server environments.
