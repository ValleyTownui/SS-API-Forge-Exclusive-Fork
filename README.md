# SS-API-Forge-Exclusive-Fork

## English

SSAPI Forge Fork is a Forge-exclusive fork of SSAPI, designed to improve compatibility and integration with Forge-based Minecraft servers.

This version focuses on providing stable API functionality and seamless support for Forge server environments.
